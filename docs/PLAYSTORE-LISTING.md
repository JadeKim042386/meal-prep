- 4가지 모드: 균형 잡힌 식단 / 한식 위주 / 고단백 위주 / 초간편 위주
- 같은 메뉴 중복 방지, 카테고리·영양 자동 분산

🛒 장보기 리스트 자동 정리
- 식단표 기반으로 필요한 모든 재료 자동 집계
- 정육·채소·유제품·곡물·양념 6개 카테고리로 분류
- 같은 재료는 단위별 합산 (예: 양파 1개 + 1/2개 = 1.5개)
- 갯수 단위 재료에 무게 환산 자동 표시 (예: 양파 1개 → 약 200g)

- 주간 식단의 모든 요리를 4단계로 분류:
  1단계 장시간 조리(찜·스튜) 먼저
  2단계 오븐·시트팬 (예열 시간 활용)
  3단계 빠른 볶음·구이 (마지막)
  4단계 회·샐러드 (주중 별도)
- D-1 밑준비 체크리스트 (양념장·핏물·채소 손질·곡물 불리기·용기 라벨링)

- 칼질·썰기 (12개, SVG 일러스트 + YouTube 영상 링크)
- 재료 손질 (13개, 데치기·핏물·해동 등)
- 조리 기법 (14개, 시어링·예열·볶음 순서)
- 양념·소스 황금비 (14개, 만능 양념장·불고기·데리야끼 등)
- 보관·재가열 (14개, 냉장/냉동 기준·라벨링)
- 문제 해결 (14개, 너무 짤 때·비린내·탄 음식 살리기)

🔄 대체 재료 정보 100여 종
- 각 레시피의 재료 옆에 대체 가능한 식재료 자동 표시
- 예: 닭가슴살 → 닭다리살/닭허벅지살, 미림 → 청주/맛술
- 마트에서 못 구한 재료도 걱정 없이

💡 단계별 인라인 팁
- 조리법의 각 단계에 관련된 요리 팁 자동 매칭
- 단계 옆 "💡 Tip" 버튼 클릭 시 펼침
- 칼질 단계에는 YouTube 영상 링크까지 함께
