# Play Console 설문 답안지

Play Console 등록 시 두 개의 큰 설문(콘텐츠 등급 / 데이터 안전)이 있습니다. 미리 답을 정리해 두면 등록이 빠르고 거부 사유를 줄입니다.

`Play Console → 정책 → 앱 콘텐츠 → 콘텐츠 등급` 에서 시작.

**카테고리 선택**: `참고 자료, 교육 또는 비즈니스 앱` (Reference, Education or Business)

| 성적 콘텐츠가 있나요? | ❌ 아니요 | 없음 |
| 욕설·비속어가 있나요? | ❌ 아니요 | 표준 한국어·영어 |
| 약물·알코올·담배 묘사? | ❌ 아니요 | 음식 재료만 |

## B. 데이터 안전 양식 (Data Safety)

`Play Console → 정책 → 앱 콘텐츠 → 데이터 안전` 에서 시작.

### B-1. 첫 질문 — 데이터 수집·공유 여부

| 질문 | 답 |
|---|---|
| 앱이 필수 사용자 데이터를 수집·공유합니까? | ✅ 예 |

| 데이터 삭제 요청을 받습니까? | ✅ 예 (이메일 jk042386@gmail.com) |

### B-2. 수집·공유 데이터 종류

대분류 14개 중 **다음 한 가지만 해당**:

#### ✅ 앱 활동 → "기타 작업 (사용자 제공 입력)"
| 항목 | 답 |
|---|---|
| 데이터 유형 | 사용자가 자발적으로 입력한 피드백 텍스트 |
| 수집되나요? | ✅ 예 |
| 공유되나요? | ✅ 예 (GitHub Issue로 공개 게시) |
| 처리되는 외부 서비스 | Supabase Edge Function · Cloudflare Turnstile · GitHub API |
| 이 데이터의 수집은 선택입니까? | ✅ 예 (피드백 모달을 사용해야만 발생) |
| 수집 목적 | 앱 기능(피드백 처리), 서비스 개선 |
| 사용자가 데이터 삭제를 요청할 수 있나요? | ✅ 예 (이메일) |

#### ❌ 다음 모두 "수집 안 함":

| 카테고리 | 답 | 비고 |
|---|---|---|
| 위치 (정확/대략) | ❌ | 미수집 |
| 개인 정보 (이름·이메일·전화·주소·신분증) | ❌ | 회원가입 없음 |
| 금융 정보 (신용카드·결제·계좌·구매내역) | ❌ | 결제 없음 |
| 건강·피트니스 데이터 | ❌ | 추적 없음 (레시피는 일반 정보) |
| 메시지 (이메일·문자·채팅) | ❌ | 없음 |
| 사진·동영상 | ❌ | 카메라·갤러리 접근 없음 |
| 음성·녹음 | ❌ | 없음 |
| 파일·문서 | ❌ | 외부 파일 접근 없음 |
| 캘린더 | ❌ | 없음 |
| 연락처 | ❌ | 없음 |
| 앱 활동 (검색 기록·페이지 뷰) | ❌ | 익명 방문자 카운터(hits.sh)는 개인 식별 불가 |
| 웹 브라우징 기록 | ❌ | 없음 |
| 앱 정보·성능 (크래시·진단 로그) | ❌ | 미수집 |
| 기기·기타 ID (광고 ID·기기 식별자) | ❌ | 추적 없음 |

### B-3. 정리

- **수집 데이터**: 사용자 피드백 텍스트 1종
- **사용 목적**: 앱 기능 (피드백 → GitHub Issue), 서비스 개선
- **공유**: Supabase·Cloudflare·GitHub (처리 위탁)
- **암호화**: 전송 중 암호화 (HTTPS), 저장은 GitHub Issue로 공개
- **선택성**: 사용자가 자발적으로 작성·전송할 때만 수집
- **삭제 요청**: 가능 (이메일 문의)
