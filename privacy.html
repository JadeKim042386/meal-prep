개인정보처리방침

밀프랩 플래너 (Meal Prep Planner) — 시행일: 2026-05-01

1. 총칙

밀프랩 플래너(이하 "본 서비스")는 사용자의 개인정보를 중요하게 생각하며, 「개인정보 보호법」 및 관계 법령에 따라 사용자의 권리를 보호하기 위해 본 방침을 수립·공개합니다.

2. 수집하는 정보

본 서비스는 다음과 같이 최소한의 정보만 수집합니다.

가. 사용자가 직접 입력하는 정보

  • 피드백 내용: 사용자가 자발적으로 피드백 모달에 입력하는 텍스트(최대 2,000자). 사용자가 "보내기" 버튼을 눌러야만 전송됩니다.

나. 자동으로 처리되는 정보

  • 로컬 저장 데이터: 사용자의 식단표·장보기 체크 상태가 브라우저 localStorage에 저장됩니다. 이 데이터는 사용자 기기에만 보관되며 외부로 전송되지 않습니다.
  • 방문자 카운터: 익명의 방문 횟수 집계를 위해 hits.sh 서비스에 핑(ping)을 보냅니다. 개인을 식별할 수 있는 정보는 포함되지 않습니다.
  • 봇 방지(Captcha): 피드백 전송 시 Cloudflare Turnstile이 봇 여부를 검증합니다. Cloudflare가 자체 정책에 따라 일시적으로 IP 등 기술 정보를 처리할 수 있습니다.

3. 정보의 이용 목적

  • 피드백 내용은 GitHub Issue로 자동 생성되어 서비스 품질 개선에 활용됩니다.
  • 방문자 카운터는 서비스 운영 통계 목적으로만 사용됩니다.
  • 로컬 저장 데이터는 사용자의 식단·장보기 상태 유지에만 사용됩니다.

4. 정보의 보관 및 파기

  • 피드백 내용은 GitHub Issue에 영구 게시되며, 사용자가 작성한 닉네임이나 식별 정보가 포함되지 않는 한 익명입니다.
  • 로컬 저장 데이터는 사용자가 브라우저 캐시를 삭제하거나 "장보기 초기화" 등 본 서비스의 초기화 기능을 사용하면 즉시 삭제됩니다.
  • 본 서비스는 별도의 서버 데이터베이스를 운영하지 않으므로 사용자 식별 정보를 저장하지 않습니다.

5. 제3자 제공 및 위탁

피드백 처리 과정에서 다음 제3자 서비스가 사용됩니다:

  • Supabase (Edge Function 실행) — 피드백 텍스트의 일시 처리
  • Cloudflare (Turnstile) — 봇 방지 검증
  • GitHub (Issue API) — 피드백 영구 보관
  • hits.sh — 익명 방문자 카운터

각 서비스의 개인정보처리방침은 해당 사이트에서 확인할 수 있습니다.

6. 사용자의 권리

  • 피드백을 보내지 않으면 본 서비스는 어떤 개인 정보도 수집하지 않습니다.
  • 이미 보낸 피드백을 삭제하고 싶으시면 아래 연락처로 요청해 주세요.
  • 로컬 저장 데이터는 브라우저 설정에서 직접 삭제할 수 있습니다.

7. 변경 사항 공지

본 방침이 변경될 경우 본 페이지를 통해 공지하며, 시행일을 명시합니다.

Privacy Policy

Meal Prep Planner — Effective: 2026-05-01

1. Overview

Meal Prep Planner ("the Service") respects user privacy and complies with applicable data protection laws (including Korea's Personal Information Protection Act and the EU GDPR). This Policy explains what data we handle, how, and why.

2. Information We Collect

a. Information you provide

  • Feedback text: Up to 2,000 characters that you voluntarily type into the feedback modal. Only sent when you click "Send".

b. Information processed automatically

  • Local storage: Your meal plan and shopping checklist are stored in your browser's localStorage. This data stays on your device and is never transmitted.
  • Visitor counter: An anonymous ping is sent to hits.sh to count visits. No personally identifying data is included.
  • Captcha: When submitting feedback, Cloudflare Turnstile verifies you are not a bot. Cloudflare may temporarily process technical info such as IP addresses per its own policy.

3. How We Use Information

  • Feedback content is automatically posted as a GitHub Issue and used to improve the Service.
  • The visitor counter is used solely for aggregate usage statistics.
  • Local storage is used only to preserve your meal plan and shopping list state.

4. Data Retention and Deletion

  • Feedback is published as a public GitHub Issue and remains there indefinitely. It is anonymous unless you choose to include identifying information.
  • Local storage is deleted whenever you clear your browser cache or use the in-app reset features.
  • The Service operates no central user database, so no user identifiers are stored on any server.

5. Third-Party Services

Feedback handling involves the following third parties:

  • Supabase (Edge Function) — transient processing of feedback text
  • Cloudflare (Turnstile) — bot prevention
  • GitHub (Issue API) — permanent feedback storage
  • hits.sh — anonymous visitor counter

Refer to each provider's privacy policy on their respective sites.

6. Your Rights

  • If you never submit feedback, the Service collects no personal data.
  • To request deletion of feedback you have submitted, please contact us using the email below.
  • Local storage data can be cleared at any time via your browser settings.

7. Changes to This Policy

Any changes will be announced on this page along with a new effective date.
