# Meal-Prep Data Artifacts

Pointer map for raw data files. Do not paste entire file contents into notes — record paths and roles only.

## JSON Sources
| File | Role |
|---|---|
| `data/ingredients.json` | Ingredient master list (Korean names, categories) |
| `data/recipes/korean.json` | Korean recipes (authored, KB-grounded) |
| `data/recipes/western.json` | Western recipes |
| `data/recipes/asian.json` | Asian (non-Korean) recipes |
| `data/recipes/mediterranean.json` | Mediterranean recipes |
| `data/recipes/mexican.json` | Mexican recipes |
| `data/recipes/quickmeal.json` | 초간편 (≤20 min) recipes |
| `data/recipes/_roster.json` | Roster of 50 dish concepts (planning artifact, not consumed) |
| `data/structured_data.json` | Built artifact: merged recipes + weeklyPlan + (archival) shoppingList |

> The scraped `data/recipes_*.json` files were removed in [[ADR 0004 Recipe Overhaul]]; `data/recipes/<category>.json` is now the source of truth.

## Scripts
- `scripts/build_data.py` — merges `data/recipes/*.json` → `data/structured_data.json` and injects `const DATA` into `index.html` (deterministic; re-runnable)
- `scripts/validate.py` — verifies recipe schema and ingredient references against the built `DATA`

## Notes
- [fact] All recipe IDs and ingredient names are Korean and serve as identifiers #identifiers
- [fact] The app's `const DATA` is GENERATED by `build_data.py` — edit `data/recipes/*.json`, never the DATA line directly #build
- [risk] `DATA.shoppingList` is archival; the app computes the shopping list live from `weeklyPlan` #risk
